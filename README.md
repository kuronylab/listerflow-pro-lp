## v1.1.0 で実現した「最強の出品フロー」

本拡張機能は、従来の出品作業に存在した「価値を生まない時間」を徹底的に削ぎ落としました。

### 🚀 実現した改善効果
- **画面往復 0回**: OpenAI GPT統合により、YaballeとChatGPTの往復を排除。
- **スクロール 0回**: Quick MIPボタンを配置し、最下部までスクロールする手間を解消。

## 💎 主な機能と進化

### 🚨 VeRO・ステータスの動的検知 [強化]

出品画面の情報をAIと連動して監視。問題がある場合は即座に通知します。

| 警告項目 | 検知対象 | 解説・対処法 |
|:---|:---|:---|
| `brand:` | ブランド名 | 禁止商標を検知。「最適化」で回避フレーズへ自動変換。 |
| `title:` | 禁止単語 | eBayポリシー違反ワード等を検知。「最適化」で削除。 |
| `protected` | 商品制限 | 出品制限中。このASINはスキップ推奨。 |
| `already listed` | 重複出品 | 履歴から重複を検知。二重出品を未然に防止します。 |
| `No item` | 該当なし | [New!] 選定した商品が見つからなかった場合のエラー。 |
| `No listings` | 情報取得失敗 | Get Item失敗時に表示。再試行またはASIN確認が必要。 |

---

### 🤖 AIタイトル最適化 & 🚀 ターボモード

OpenAI GPT-4o-mini を活用し、最強のタイトルを自動生成します。

- **精密な文字数調整**: 70〜80文字の「売れる長さ」に厳密に収めます。
- **VeRO自動回避**: 禁止語を削除し、`Fits` などの互換表現へAIが自動リライト。
- **ターボモード (Turbo)**: 
  - ASIN入力からMIP完了までを、人間が一切触れずに全自動で実行。
  - 最適化に失敗しても、AIがプロンプトを再調整して最大3回までリトライします。

---

### ⚡ Quick MIPボタン

画面のどこにいても瞬時に出品を確定できる、ショートカットボタンです。

> [!TIP]
> **✅ 有効化条件（全て満たすと点灯）**:
> 1. タイトルが **70〜80文字** 以内。
> 2. 警告単語が除去されている、または互換表現が含まれている。
> 3. `protected` / `brand` / `already listed` の警告がない。

---

### 📊 ASIN管理・エクスポート [刷新]

出品結果を自動記録し、管理表への入力を極限まで簡単にします。

- **カード型履歴**: 画面上部に最新の結果をカード形式で表示。視認性が大幅アップ。
- **🚀 出品画面から即時連携 [強化]**: 
  - オプションを開く手間すら省くため、**出品作業画面上のバーに「コピー」「CSV」ボタンを直結**。
  - 作業が終わったらその場でコピーし、スプレッドシートに貼り付けるだけで結果入力が一瞬で完了します。
- **スプレッドシート専用コピー**: 
  - **2カラム形式**: 「出品日」と「エラー日」を分けて出力。管理表への範囲ズレを防ぐ空白補完・CRLF最適化済み。

---

### 🔄 止まらない自動化・信頼性向上

**自動化・効率化項目**:
- **エラーモーダル自動消去機能**: エラーポップアップを自動（1秒後・再発時は即座）で消去。
- **UI自動リカバリー**: 万が一UIが消えても、ASIN入力欄をクリックするだけで自動復旧。
- **⏱️ 賢い作業時間タイマー**:
  - **自動スタート**: ASINを欄にペーストした瞬間に計測を開始。
  - **自動ストップ**: 最後の作業から**2分間**経過すると自動停止。休憩時間を自動除外します。
  - **手動コントロール**: 再生・一時停止ボタンでいつでも操作可能。

## 🛠️ オプション設定の完全ガイド

拡張機能アイコンをクリックして開くポップアップメニュー(☰)の全機能解説です。

### 1️⃣ 📊 統計情報
本日の進捗とパフォーマンスをリアルタイムで分析します。
- **出品統計**: 本日/今週/累計の出品数と、最終出品時刻。
- **🚀 作業効率**: 実作業時間と「出品速度ランク（爆速🚀・高速🏎️など）」の表示。
- **ASIN履歴統計**: エラー率の実数値と、エラー種別ごとのカウント。

### 2️⃣ 📋 ASIN履歴管理
出品・エラーの全全記録を確認・出力します。
- **履歴リスト**: 最新の履歴をカード形式で表示。個別の削除（✕ボタン）も可能。
- **スプレッドシート用に出力**: 管理表への転記を自動化するクリップボードコピー。
- **履歴をすべて削除**: 店舗切り替え時などのリセット用。

### 3️⃣ 🤖 自動化設定
挙動をあなた好みにカスタマイズします。
| 設定項目 | 役割 | 初期値 |
|:---|:---|:---|
| **ASINペースト時にGet Item自動実行** | 貼り付けた瞬間に商品取得を開始 | **ON** |
| **ASIN履歴選択時にGet Item自動実行** | 履歴クリックで即座に商品情報を呼び出し | **ON** |
| **最適化後MIP自動クリック** | AI最適化が完了したらそのまま出品 | OFF |
| **MIP後にOKボタン自動クリック** | 「Listing Success」を自動で閉じる | **ON** |
| **最速出品モード (Turbo Mode)** | 上記をすべて連携させた全自動フロー | OFF |
| **Quick MIPボタン表示** | 作業画面へのショートカットボタン表示 | **ON** |
| **最適化ボタン追加** | タイトル欄横へのAIボタン表示 | **ON** |
| **作業時間パネルの表示** | 画面上部へのタイマー・速度バッジ表示 | **ON** |
| **ASIN履歴管理** | 履歴の追記と重複出品チェック | **ON** |
| **VeRO警告チェック** | 禁止単語の自動検出とマーキング | **ON** |

### 4️⃣ ⚙️ 基本設定
心臓部であるAIエンジンの設定です。
- **OpenAI API Key**: タイトル最適化に使用するキーを入力。
- **モデル**: `gpt-4o-mini`（高速かつ安価な推奨モデル）を選択。

### 5️⃣ 🔗 各種リンク
作業をスムーズに開始・継続するためのポータルです。
- **🚀 Yaballe公式サイト**: **【重要】** 拡張機能からワンクリックで出品画面へ。
- **YouTubeプレイリスト**: 常に最新の使いかたを確認可能。
- **LINEグループ / メール**: 困った時の公式サポート窓口。
