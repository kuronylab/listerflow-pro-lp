##  v1.1.0 で実現した「最強の出品フロー」

本拡張機能は、従来の出品作業に存在した「価値を生まない時間」を徹底的に削ぎ落としました。

### 🚀 実現した改善効果
- **画面往復 0回**: OpenAI GPT統合により、YaballeとChatGPTの往復を排除。
- **スクロール 0回**: Quick MIPボタンを配置し、最下部までスクロールする手間を解消。
- **待機時間の圧縮**: 出品後の「OKボタン」自動クリックにより、ノンストップで次へ。
- **作業時間の可視化**: リアルタイム計測とランクシステムでモチベーションを維持。

## 主な機能

### 🚨 VeRO・ステータスの動的検知 [v1.1.0 強化]

出品画面の情報をAIと連動して監視。問題がある場合は即座に通知します。

| 警告項目 | 検知対象 | 解説・対処法 |
|:---|:---|:---|
| `brand:` | ブランド名 | 禁止商標を検知。「最適化」で回避フレーズへ自動変換。 |
| `title:` | 禁止単語 | eBayポリシー違反ワード等を検知。「最適化」で削除。 |
| `protected` | 商品制限 | 出品制限中。このASINはスキップ推奨。 |
| `already listed` | 重複出品 | 履歴から重複を検知。二重出品を未然に防止します。 |
| `No listings` | 情報取得失敗 | Get Item失敗時に表示。再試行またはASIN確認が必要。 |

---

### 🤖 AIタイトル最適化 & 🚀 ターボモード

OpenAI GPT-4o-mini を活用し、最強のタイトルを自動生成します。

- **精密な文字数調整**: 70〜80文字の「売れる長さ」に厳密に収めます。
- **VeRO自動回避**: 禁止語を削除し、`Fits` などの互換表現へAIが自動リライト。
- **ターボモード (Turbo) [v1.1.0 新機能]**: 
  - ASIN入力からMIP完了までを、人間が一切触れずに全自動で実行。
  - 最適化に失敗しても、AIがプロンプトを再調整して最大3回までリトライします。

---

### ⚡ Quick MIPボタン

画面のどこにいても瞬時に出品を確定できる、ショートカットボタンです。

**✅ 有効化条件（全て満たすと点灯）**:
1. タイトルが **70〜80文字** 以内。
2. 警告単語が除去されている、または互換表現が含まれている。
3. `protected` / `brand` / `already listed` の警告がない。

---

### 📊 ASIN管理・エクスポート [v1.1.0 刷新]

出品結果を自動記録し、管理表への入力を極限まで簡単にします。

- **カード型履歴**: 画面上部に最新の結果をカード形式で表示。視認性が大幅アップ。
- **スプレッドシート専用コピー**: 
  - **2カラム形式**: 「出品日」と「エラー日」を分けて出力。
  - **貼り付けズレ防止**: 空白セルの補完と改行コード(CRLF)の最適化。
- **CSVダウンロード**: 全履歴を管理用にワンクリック保存可能。

 ### 🔄 止まらない自動化・信頼性向上
 
 v1.1.0では「作業を止めないこと」に徹底的にこだわり、システムの信頼性を大幅に向上させました。
 
 **自動化・効率化項目**:
 - **エラーモーダル自動消去機能（v1.1.0）**: エラー商品のポップアップが表示された際に、自動（1秒後・再発時は即座）で消去することで、より快適に次のASIN入力に進めることができます。
 - **通信プロトコルの安定化（v1.1.0）**: ブラウザ拡張機能特有の通信切断エラーを徹底排除。タイマー同期や統計更新の失敗がなくなりました。
 - **UI自動リカバリー（v1.1.0）**: 万が一ブラウザの挙動でUIが消えても、ASIN入力欄をクリックするだけで自動的に再描画・復旧します。
 - **MIP成功後のOKダイアログ自動クリック**: 成功時の確認ボタンも自動化。
 - **作業時間・ランク表示（v1.1.0）**: 本日の作業時間と「出品ペース（ランク）」をリアルタイム表示。ノリノリで作業を進められる遊び心を追加しました。
 - ASINペースト時 / 履歴選択時のGet Item自動実行
 - 最適化後にMIPを自動クリック（オプション）

## インストール方法

### 1. ZIPファイルをダウンロード
[GitHub リリースページ](https://github.com/kuronylab/listerflow-pro-for-yaballe/releases)から最新版のZIPファイルをダウンロードしてください。

### 2. Chrome拡張機能として読み込む
1. ダウンロードしたZIPファイルを任意の場所に解凍します。
2. Chromeブラウザで `chrome://extensions/` を開きます。
3. 右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、解凍したフォルダを選択します。

### 3. OpenAI APIキーの設定
1. 拡張機能アイコン（パズルマーク 🧩）から「ListerFlow Pro」をピン留めします。
2. ポップアップを開き、メニュー(☰) ＞ 「基本設定」を選択。
3. OpenAIのAPIキーを入力し、「設定を保存」をクリックしてください。

## 使い方・操作ガイド

### 🚀 ターボモードで全自動出品
最速で作業を進めたい場合の推奨フローです。
1. **設定**: ポップアップの「自動化設定」で「最速出品モード (Turbo)」をONにします。
2. **実行**: YaballeのASIN入力欄にASINを貼り付けます。
3. **完了**: 自動で商品取得、タイトル最適化、MIP出品が完了し、成功ダイアログも自動で閉じます。

### 🖱️ 手動（確認）出品
内容を目で確認しながら進めたい場合のフローです。
1. ASINを入力すると自動で商品情報が取得されます。
2. タイトル横の「最適化」ボタンをクリックし、AIに最適なタイトルを作らせます。
3. 条件（70〜80文字・警告なし）を満たすと「Quick MIP」ボタンが点灯。クリックして出品します。

## トラブルシューティング

| 症状 | 原因と対策 |
|:---|:---|
| ボタンが表示されない | ページをリフレッシュ（F5）してください。通信の安定性が向上していますが、初回読み込み時に失敗することがあります。 |
| Quick MIPが押せない | タイトルが **70〜80文字** であること、および重大なVeRO警告（Protected等）がないことを確認してください。 |
| APIエラーが出る | APIキーが正しいか、OpenAIのクレジット残高が十分かを確認してください。 |
| UIが消えた | 万が一UIが消えた場合は、ASIN入力欄を一度クリックすると自動で再描画（リカバリー）されます。 |
